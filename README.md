# Suhan Apology Website 💗🧸🥭

A tiny interactive apology website made specifically for Suhan.

## The flow

1. **Suhan, are you angry with Prashant?**
2. If she chooses **Yes**, the site playfully asks **Are you sure?** and then **You really sure?**
3. If she chooses **No** (or changes her mind), she reaches **Prashant wants to say something…**
4. She opens a personal apology note.
5. The note can be edited before publishing the site.
6. The ending gives her **I forgive you** / **Still mad** choices.
7. Forgiveness triggers hearts, teddy bears, Maaza and a little celebration.

## Personalize the apology

Open `script.js` and edit `defaultNote` near the top. Replace it with your own message to Suhan.

The browser also saves the edited note in localStorage while testing.

## Run locally

Double-click `index.html` or open it in a browser.

## GitHub Pages

Upload `index.html`, `style.css`, and `script.js` to a repository. Then enable GitHub Pages for the repository. There is no build step.

## Design

The visual direction follows the provided pink/glassmorphism reference: soft pink gradients, floating hearts, teddy bears, mango-drink bottles, rounded buttons, and gentle animations.
